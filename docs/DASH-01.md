# DASH-01: Admin dashboard and homepage statistics

Implemented step 1 of the approved dashboard design. Menu/price management and owner dashboard remain steps 2 and 3.

- `/admin/dashboard`: authenticated Admin report, Vietnam calendar date range (default last 30 days), category filter, current place counts, website visits and comparison with an equally long previous period, daily traffic, top 10 viewed places, submitted contributions and published review distribution. Queue totals are current and system-wide, independent of the report interval. Website traffic is site-wide even when filtering a category.
- Homepage: two compact counters above the footer, on desktop and mobile: places gated by `api.public_places`, and total measured website visits. Real zero remains zero; network errors show an unavailable state rather than fabricated counts.
- Existing place lifetime counters are preserved. Daily history starts with migration 0013; old lifetime counts are not backfilled into daily buckets.
- Signed anonymous session cookie uses existing `USER_SESSION_SECRET`, falling back to `ADMIN_SESSION_SECRET`. No new env variable is required. Website sessions slide with activity and expire after 30 minutes of inactivity. Place views deduplicate per place/session for 30 minutes. First-party POST requests only; recognizable bots and authenticated Admin sessions are excluded.
- A shared client request initializes the cookie before place-view requests. Active public pages send at most one activity heartbeat per minute. Browser cookie blocking can reduce deduplication accuracy; visits represent sessions, not unique people. Bot filtering is heuristic.
- Only session hashes, targets and last-seen times are retained for deduplication, with bounded cleanup after two days. Daily aggregate counts remain. No raw IP or viewer identity is stored.
- Apply `migrations/0013_dashboard_metrics.sql` after 0012. It adds tables and indexes, changes no existing place/category/review data, and is re-runnable. Tested on Neon branch `test-dashboard-20261104`; applied to the existing 11Local main database on 2026-11-04.

Validation: lint (two pre-existing warnings), 84 tests and production build. Dashboard SQL executed against the isolated Neon branch. `scripts/test-analytics.sql` checks initial counting, repeated-view suppression, 30-minute expiry and daily aggregation inside a rolled-back subtransaction. Local HTTP checks confirm Admin authorization, origin rejection and bot exclusion. Full HTTP-to-Neon smoke is blocked by the executor's direct PostgreSQL DNS access; no end-to-end production verification claimed.
